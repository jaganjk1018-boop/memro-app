# Memro — Smart Cognitive Care Companion

An assistive AI and voice-first cognitive companion designed for elders with mild cognitive impairment or early dementia, their primary caregivers, and family members. Built with multi-language support (22 official Indian languages + English), tactile UI, memory recall therapy, medication reminders, and caregiver monitoring.

---

## 🌟 Key Features

### 👵 1. Elder / Patient Companion (Amma Companion)
- **Voice-Guided Navigation**: Audio cues and speech prompts in English, Hindi, Tamil, Telugu, Bengali, Assamese, and 17+ Indian regional languages.
- **Cognitive Memory Games**: Joyful card-matching memory exercises to stimulate cognitive recall.
- **Daily Reminders**: Visual and audio alerts for medications, meals, daily walks, and hydration.
- **Family Photo Memories**: Face & relationship recognition practice with personalized voice feedback.
- **Calm & Deep Breathing**: Visual pranayama breathing exercises to soothe anxiety and sundowning distress.

### 🛡️ 2. Caregiver Routine Hub
- **Medication Scheduling & Adherence**: Track scheduled dosages and verify medicine intake.
- **Secure Access**: PIN-protected caregiver settings (`1234`).
- **Routine Diary & Mood Tracking**: Daily logs of elder wellbeing and activity engagement.

### 👨‍👩‍👧 3. Family Circle Portal
- **Loved Ones Check-in**: High-level wellbeing status and engagement scores.
- **Memory Sharing**: Upload family pictures and milestones for elder recognition practice.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Running Locally

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd memro-cognitive-companion
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
